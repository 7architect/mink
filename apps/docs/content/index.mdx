## First implementation

Mink 0.1 is an alpha for **Linux and macOS with Node.js 24 or newer**. It includes an interactive Ink interface and a scriptable CLI backed by the same execution engine. Build it from this repository; packages have not been published as part of this change.

Begin with the [quick start](/quickstart/), try the runnable `examples/demo` project, or read the [architecture](/architecture/). Windows support, persistent background sessions, Makefile/Taskfile/Compose import, plugins, and remote execution remain future work.
