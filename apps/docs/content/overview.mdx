# Mink

Mink is a terminal palette for the commands, pipelines, and local services that already live in your repository. Start with discovered `package.json` scripts, then add a `mink.yml` when a command needs parameters, a clearer name, or a workflow.

Mink 0.1 is an alpha for **Linux and macOS with Node.js 24 or newer**. It includes an interactive Ink interface and a scriptable CLI backed by the same execution engine. Build it from this repository; packages are not published yet.
